# Search & Discover Recipes

Stitch screen `8b4acd8f01ee42abbb7bc15fe61218d6` from project `8025779433225668963`
(SeasonPal Recipe Sharing App).

Search results: query bar with filter button and active-filter count, quick filter chips,
a "match with my pantry" toggle, trending searches with clear-history, curated collection
cards, and a relevance-sorted result list with pantry-match badges, compact rows and an
AI-adjustment prompt.

## Files

- `screen.html` — exported HTML/Tailwind markup. Loads the Tailwind CDN and Google Fonts,
  so it needs network access to render.
- `screenshot.png` — full-page reference render (487x2250).

Designed at 780x3644. Copy in the export is English; colors, type and spacing follow
`docs/design/DESIGN.md`.
