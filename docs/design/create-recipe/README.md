# Create Recipe Studio

Stitch screen `aad944be42744b64b22c36a942f52245` from project `8025779433225668963`
(SeasonPal Recipe Sharing App).

Recipe editor: cover media upload, title and story with character counters, public/private
visibility, kitchen metrics (cuisine, servings, prep/cook time, complexity), selected
kitchen gear, a reorderable ingredient list, numbered cooking steps with optional photos,
free-form tags, and publish or save-as-draft actions.

## Files

- `screen.html` — exported HTML/Tailwind markup. Loads the Tailwind CDN and Google Fonts,
  so it needs network access to render.
- `screenshot.png` — full-page reference render (487x3077).

Designed at 780x4994. Copy in the export is English; colors, type and spacing follow
`docs/design/DESIGN.md`.
