# Recipe Detail View

Stitch screen `f7f02cbd2d754ebcb8d80a7446f15fd8` from project `8025779433225668963`
(SeasonPal Recipe Sharing App).

Recipe page: hero photo with seasonal badge, share and save, cuisine/difficulty/rating
chips, author row with follow, prep/cook/servings strip, required kitchen gear, an
ingredient checklist with a pantry-readiness count, numbered preparation steps with timers
and a photo, and a pinned start-cooking-mode action.

## Files

- `screen.html` — exported HTML/Tailwind markup. Loads the Tailwind CDN and Google Fonts,
  so it needs network access to render.
- `screenshot.png` — full-page reference render (487x1962).

Designed at 780x3406. Copy in the export is English; colors, type and spacing follow
`docs/design/DESIGN.md`.
