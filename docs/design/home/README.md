# Home — Discover & Seasonal Feed

Stitch screen `fdbd7fa076ee40808c887a1033073203` from project `8025779433225668963`
(SeasonPal Recipe Sharing App).

Signed-in home feed: seasonal edition header, search, filter chips, a "today's
centerpiece" hero recipe with cook-now action, a horizontal community cooklist rail,
cooks-of-the-week ranking, and the five-tab bottom bar with a raised create button.

Designed at 780x3590. Copy in the export is English; colors, type and spacing follow
`docs/design/DESIGN.md`.
